# Big Star Machinery – Inventory Photo and Listing Package

This ZIP contains the original uploaded images organized by product, plus editable listing copy in `listings.csv` and `listings.md`. No live website or GitHub files were modified.

## How to use
1. Unzip locally.
2. Upload the desired `inventory-assets/` folders to your GitHub repository (or use GitHub Add file > Upload files).
3. Update the corresponding existing website product records to point to the new image paths and paste the descriptions from `listings.md` / `listings.csv`. **Uploading this ZIP alone does not automatically change the website listings.**
4. Keep existing prices, SKUs and stock values unless you confirm changes. Verify model-specific specifications and engine warranty paperwork before publishing.

Images are grouped using the photos visible in this conversation. `other-attachments` contains additional uploaded product photos that should be matched to existing listings before publishing.
