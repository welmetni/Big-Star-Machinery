BIG STAR MACHINERY - WEBSITE UPDATE

Includes 13 original uploaded equipment photos and a script that updates your current GitHub website.

1. Download your current GitHub repository as a ZIP: https://github.com/welmetni/Big-Star-Machinery (Code > Download ZIP).
2. Extract that repository ZIP to a folder on your PC.
3. Open this update ZIP and copy BOTH the assets folder and apply_bigstar_update.py into the repository folder next to index.html and inventory.js. Choose Merge folders if asked.
4. In that repository folder, run: python apply_bigstar_update.py
   (Python 3 is required.)
5. Verify the site locally. The script keeps .bak backups of index.html and inventory.js.
6. Upload the changed index.html, inventory.js and all 13 photos in assets/images/inventory/nov2026-update/ to the same paths in your GitHub repository. Commit changes together.
